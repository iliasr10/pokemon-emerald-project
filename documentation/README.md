# Pokémon Emerald Project Documentation

This directory contains the ROM hack's **project-specific** documentation. It is intentionally separate from the upstream `docs/` directory, which should remain intact.

## Documents

- [`GAME_DESIGN.md`](GAME_DESIGN.md) — Living Game Design Document. Section 1 is drafted; later sections are placeholders awaiting review.
- [`DECISIONS.md`](DECISIONS.md) — Working record of confirmed directions, tentative ideas, and open questions.
- [`ROADMAP.md`](ROADMAP.md) — Initial project progress and documentation milestones; future development milestones are not yet defined.

## Editing principles

1. Distinguish agreed design directions from unapproved proposals.
2. Preserve the reasoning behind important choices.
3. Prefer small, reviewed updates through feature branches and pull requests.
4. Keep implementation details separate until verified in the codebase.
